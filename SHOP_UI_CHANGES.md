# Изменения в системе магазина, инвентаря и меню паузы

## Что было сделано

Реализована система приоритетов для обработки клавиши ESC:
1. Если открыт магазин - ESC закрывает магазин
2. Если открыт инвентарь игрока - ESC закрывает инвентарь
3. Если ничего не открыто - ESC открывает/закрывает меню паузы

## Изменённые файлы

### 1. `Assets/!SeriouslyProject/Scripts/Shop/ShopUI.cs`

**Добавлено:**
- Поле `[SerializeField] private MainUI mainUI;` для ссылки на MainUI
- Автопоиск MainUI в методе `Awake()` если не назначен в инспекторе

**Изменения в методе `OpenShop()`:**
- При открытии магазина устанавливается `mainUI.canOpenUI = false`
- Это блокирует открытие меню паузы и инвентаря

**Изменения в методе `CloseShop()`:**
- При закрытии магазина устанавливается `mainUI.canOpenUI = true`
- Это разблокирует UI перед закрытием магазина

### 2. `Assets/!SeriouslyProject/Scripts/UI/PauseMenu.cs`

**Изменения в методе `Update()`:**

Добавлены две проверки в начале обработки клавиши ESC:

**Проверка 1 - Магазин:**
```csharp
if (_mainUIInstance.shopUI != null && _mainUIInstance.shopUI.IsShopMode)
{
    _mainUIInstance.shopUI.CloseShop();
    return;
}
```

**Проверка 2 - Инвентарь игрока:**
```csharp
if (_mainUIInstance.isOpenUI && _mainUIInstance.playerUI != null)
{
    GameObject playerUIbackGround = _mainUIInstance.playerUI.transform.GetChild(0).gameObject;
    if (playerUIbackGround.activeInHierarchy)
    {
        playerUIbackGround.SetActive(false);
        _mainUIInstance.isOpenUI = false;
        return;
    }
}
```

## Как это работает

### Приоритет обработки ESC:

1. **Магазин открыт:**
   - ESC закрывает магазин
   - Выход через `return` - меню паузы НЕ открывается

2. **Инвентарь игрока открыт:**
   - ESC закрывает инвентарь
   - Сбрасывается флаг `isOpenUI`
   - Выход через `return` - меню паузы НЕ открывается

3. **Ничего не открыто:**
   - ESC работает как обычно - открывает/закрывает меню паузы

### Блокировка UI при открытом магазине:

1. **Открытие магазина:**
   - Устанавливается `canOpenUI = false`
   - Меню паузы не может открыться
   - Инвентарь не может открыться (клавиша E)

2. **Закрытие магазина:**
   - Устанавливается `canOpenUI = true`
   - UI разблокируется

## Преимущества решения

✅ Магазин блокирует меню паузы и инвентарь
✅ ESC закрывает магазин (приоритет 1)
✅ ESC закрывает инвентарь (приоритет 2)
✅ ESC открывает меню паузы только если ничего не открыто (приоритет 3)
✅ Меню паузы не открывается сразу после закрытия магазина/инвентаря
✅ Согласуется с существующей архитектурой проекта
✅ Интуитивное поведение для игрока

## Настройка в Unity

В инспекторе ShopUI можно назначить MainUI вручную, но если не назначено - компонент найдётся автоматически через `FindObjectOfType<MainUI>()`.
