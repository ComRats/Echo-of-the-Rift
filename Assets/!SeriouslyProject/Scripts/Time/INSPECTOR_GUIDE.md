# Управление временем через Inspector

## TimeManager - Управление временем

### Debug Info (только чтение)
- **Current Time** - текущее время в формате HH:MM
- **Current Day** - текущий день
- **Current Period** - текущий период суток (Morning/Day/Evening/Night)

### Time Control - Установка времени
- **Час (0-23)** и **Минута (0-59)** - выберите нужное время
- **Кнопка "Установить время"** - применить выбранное время

### Quick Actions - Быстрая установка
- **Утро (6:00)** - установить время на 6:00
- **День (12:00)** - установить время на 12:00
- **Вечер (18:00)** - установить время на 18:00
- **Ночь (0:00)** - установить время на полночь

### Skip Time - Пропуск времени
- **Часов (1-24)** - выберите количество часов для пропуска
- **Кнопка "Пропустить"** - пропустить выбранное количество часов
- **Пропустить до утра** - пропустить время до 6:00

### Time Scale - Скорость времени
- **Нормальная (1x)** - обычная скорость времени
- **Быстрая (5x)** - ускоренная скорость (в 5 раз быстрее)
- **Пауза** - остановить время
- **Возобновить** - продолжить отсчёт времени

## DayNightCycle - Настройка освещения

### Lighting Setup
- **Global Light** - назначьте Light2D (Global) из сцены
  - Если не назначен, будет найден автоматически

### Debug Info (только чтение)
- **Current Light Color** - текущий цвет освещения
- **Current Light Intensity** - текущая яркость (0-2)
- **Current Period Name** - название текущего периода
- **Transition Progress** - прогресс перехода между периодами (0-1)

### Time Periods - Настройка периодов
Массив настроек для каждого периода суток:

Для каждого периода настраивается:
- **Period Name** - название (для отладки)
- **Start Hour** - час начала периода (0-23)
- **Light Color** - цвет освещения
- **Light Intensity** - яркость света (0-2)

**Кнопка "Создать настройки по умолчанию"** - создаёт 6 предустановленных периодов:
1. Ночь (0:00) - тёмно-синий, яркость 0.3
2. Рассвет (5:00) - оранжево-розовый, яркость 0.6
3. Утро (7:00) - светло-жёлтый, яркость 0.9
4. День (12:00) - белый, яркость 1.0
5. Вечер (18:00) - оранжевый, яркость 0.7
6. Сумерки (20:00) - фиолетовый, яркость 0.4

### Debug
- **Show Debug Info** - выводить информацию в консоль каждый кадр

## Советы по использованию

### Тестирование времени суток
1. Откройте TimeManager в инспекторе
2. Используйте Quick Actions для быстрого переключения
3. Наблюдайте за изменением освещения в Scene view

### Настройка своих периодов
1. В DayNightCycle нажмите "Создать настройки по умолчанию"
2. Измените цвета и яркость под свою игру
3. Добавьте или удалите периоды по необходимости
4. Периоды автоматически сортируются по времени начала

### Отладка
1. Включите "Show Debug Info" в DayNightCycle
2. Смотрите консоль для подробной информации
3. Используйте Debug Info секции для мониторинга в реальном времени

### Работа в Play Mode
- Все кнопки работают только в Play Mode
- Изменения времени применяются мгновенно
- Освещение меняется плавно с интерполяцией
